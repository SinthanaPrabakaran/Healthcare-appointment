# PulseFlow Care

Build a state-of-the-art, hyper-modern, and aesthetically stunning Healthcare & Consultation Management Web Application called "PulseCare". 

### 🎨 DESIGN AESTHETICS & THEME

- Components: Glassmorphism cards with subtle border gradients, backdrop blur, glowing status pills, responsive sidebar/navbar, interactive modals, floating countdown timers, smooth tab switches, and Lucide React icons.

---

### 👤 THREE USER ROLES & WORKFLOWS

Provide a quick Role Switcher toggle in the header or sidebar (Patient / Doctor / Admin) so all screens can be previewed seamlessly.

#### 1. PATIENT INTERFACE

- Navigation: Dashboard | Find Doctors | My Appointments | Medication Reminders | Google Calendar Sync

- Patient Dashboard:

  - Header with patient greeting, quick stats (Upcoming Visits, Prescriptions Active, Reminders Today).

  - Google Calendar Sync Status Widget (Connected / Disconnected with 1-click Google OAuth sync button).

  - Quick Search bar for doctors by specialization or name.

  - Urgency Triage Alert Banner for recent bookings.

- Doctor Search & Booking Flow:

  - Doctor Directory: Grid of doctor cards showing photo avatar, name, specialization tag, slot duration (e.g. 30 mins), experience, ratings, and "Book Consultation" button.

  - Interactive Booking Modal:

    1. Date Selector (Calendar picker excluding doctor leave dates).

    2. Interactive Slot Grid: Time slots (e.g., 09:00 AM, 09:30 AM). Green = Available, Red = Booked, Yellow/Flashing = Currently Held.

    3. 5-Minute Hold Countdown Banner: Selecting a slot locks it for 5:00 minutes with a live countdown timer ("Slot held! Confirm within 04:59").

    4. Symptoms Input Form: Textarea for patient chief complaints & symptoms.

    5. AI Pre-Visit Triage Card: Live Gemini AI summary preview showing Urgency Level (Low / Medium / High badge with color fill), Chief Complaint summary, and 3 suggested diagnostic questions for the doctor.

    6. Confirm Booking Button with instant state update.

- My Appointments List:

  - Cards displaying doctor info, date, time slot, appointment status (BOOKED, HELD, COMPLETED, CANCELLED).

  - Status badges with distinct visual treatments.

  - Filter tabs: All | Upcoming | Completed | Cancelled.

- Appointment Details Timeline View:

  - Complete visit history including:

    - Pre-Visit AI Triage Box (Urgency level, chief complaint summary, doctor questions).

    - Post-Visit Consultation Notes & Diagnosis.

    - Plain-Language Patient Summary generated by Gemini AI.

    - Digital Prescription Table: Columns for Medicine Name, Dosage, Frequency, Duration, Special Instructions.

    - Follow-Up Care Instructions box.

    - Add to Google Calendar button.

- Medication Reminders Page:

  - Cards for daily medicine schedules with scheduled intake times.

  - Interactive "Mark as Taken" checkbox button with progress bar for daily compliance.

  - Nodemailer email reminder notification toggle settings.

#### 2. DOCTOR INTERFACE

- Navigation: Doctor Dashboard | Patient Queue & Appointments | Consultation Suite | Working Schedule

- Doctor Dashboard:

  - Today's Queue Timeline: Chronological list of today's patient appointments.

  - Metric Cards: Patients Today, Consultations Pending, Completed Today, Urgent Cases.

  - Quick action to jump directly into the active patient consultation room.

- Interactive Consultation Suite:

  - Split View Layout:

    - Left Column: Patient Profile & Gemini AI Pre-Visit Triage (Urgency badge, chief complaint, 3 pre-visit suggested diagnostic questions).

    - Right Column: Live Clinical Workspace.

      - Chief Diagnosis & Clinical Notes Input.

      - Dynamic Prescription Builder: Add/remove medication rows with inputs for Medicine, Dosage (e.g., 500mg), Frequency (e.g., Twice daily after meals), Duration (e.g., 7 days), Instructions.

      - Follow-up instructions input field.

      - "Generate AI Patient Summary" button which calls Gemini to create a plain-language summary for the patient.

      - "Complete Consultation & Send Prescription" submit button.

- Doctor Calendar & Schedule Settings:

  - View working hours per day (Mon - Fri, 09:00 - 17:00).

  - Slot duration setting (15, 30, or 45 min intervals).

  - Mark Leave Dates date-picker with automatic patient cancellation preview modal.

#### 3. ADMIN INTERFACE

- Navigation: Overview Analytics | Doctor Management | Appointment Audit Logs

- Admin Dashboard:

  - Global system metrics: Total Doctors, Total Registered Patients, Total Appointments, AI Summaries Generated.

- Doctor Management Suite:

  - Add New Doctor Modal: Create user credentials, specialization dropdown, slot duration, working hours builder.

  - Doctor Table: Columns for Name, Specialization, Working Hours, Slot Duration, Actions (Edit, Mark Leave, Delete).

  - Leave Management Dialog: Select leave date range for a doctor. Automatically warns: "This will cancel X existing patient appointments and trigger email notifications."

---

### 🔌 DATA & API ALIGNMENT

Ensure the React components use clean state management and props structure compatible with the following REST API endpoints:

- Auth: `/api/auth/login`, `/api/auth/register`

- Doctors: `/api/doctors`, `/api/doctors/:id/slots?date=YYYY-MM-DD`

- Appointments: `/api/appointments/hold`, `/api/appointments/:id/confirm`, `/api/appointments/my`, `/api/appointments/doctor`, `/api/appointments/:id/previsit-summary`, `/api/appointments/:id/complete`

- Calendar: `/api/calendar/connect`, `/api/calendar/status`
